# Banking-System-CPP
A complete Bank Management System developed in C++ using OOP concepts and modular design. The system simulates real-world banking operations through a console interface and is structured into multiple layers for better organization and scalability.

Core Features:
Client Management
Add, update, delete, and search for clients
Store and manage client personal and account data
User Management System
Create and manage system users
Role-based access control using permission flags
Secure login system with limited attempts
Transactions Module
Deposit and withdraw money
Transfer funds between accounts
Maintain transfer logs and transaction history
Display total balances across all clients
Currency Exchange System
View available currencies and exchange rates
Update currency rates
Convert between currencies using real-time rates
Logging System
Login/Register logs
Transfer logs with detailed transaction tracking
